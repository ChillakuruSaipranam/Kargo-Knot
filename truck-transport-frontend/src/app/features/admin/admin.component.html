System Administration

Administration

Manage users, roles, and system configuration. Backend integration required.

User Access Control

Planned for .NET backend with role-based authorization.

Administrator Role

  • Create, edit, and delete trip records
  • Manage user accounts
  • View all operational reports
  • Configure quarry and truck master data

Standard User Role

  • Create and edit own trip records
  • Search and filter trip data
  • View dashboard summaries
  • No delete or user management access

Backend Endpoints (Planned)

  • POST /api/auth/login
  • GET /api/users (Admin)
  • POST /api/users (Admin)
  • GET /api/trips?filters...
  • POST /api/trips
  • PUT /api/trips/:id
  • DELETE /api/trips/:id (Admin)
